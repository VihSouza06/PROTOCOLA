# PROTOCOLA

Sistema web para registro, acompanhamento e gerenciamento de solicitações públicas, ele permite que cidadãos registrem solicitações relacionadas a problemas urbanos, Cada solicitação recebe um número de protocolo único, permitindo que o cidadão acompanhe o andamento da demanda. Além disso, gestores públicos podem visualizar, analisar e atualizar o status das solicitações registradas.

## Funcionalidades

### Cidadão

* Cadastro de usuário
* Registro de solicitações
* Geração automática de protocolo
* Consulta de solicitações por protocolo
* Acompanhamento do status da solicitação

### Gestor

* Visualização de todas as solicitações
* Consulta detalhada das demandas
* Atualização do status das solicitações
* Controle do fluxo de atendimento


## Tecnologias Utilizadas

### Backend

* Java 21
* Spring Boot

* Spring Data JPA

### Frontend

* HTML5
* CSS3
* JavaScript
